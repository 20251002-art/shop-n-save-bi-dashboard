# Shop N Save Retail BI Dashboard

This is an academic Business Intelligence dashboard built with Streamlit and Plotly.

**Important:** The sales dataset is synthetic and is not actual Shop N Save business data.

## Files required
- `app.py`
- `requirements.txt`
- `Shop_N_Save_Synthetic_Sales_2025.csv`

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

Deploy on Streamlit Community Cloud by choosing this repository and setting the main file path to `app.py`.
